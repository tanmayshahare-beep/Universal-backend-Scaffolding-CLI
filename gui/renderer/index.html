How it works
01 Select your frontend project folder below
02 Use the sidebar to toggle backend features ON / OFF and fill in their settings
03 Click Generate & Inject SDK — saves skeletal.config.json and copies the client SDK into your frontend
04 Click Start Server — your backend is live on the configured port
